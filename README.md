# Sign-up Page

A basic sign-up form page built while learning HTML & CSS.

## What it has

- A form with First Name, Last Name, and Email fields
- A Sign-up button
- Card-style layout centered on the page using Flexbox
- Basic styling: colors, border-radius, hover effect on the button

## Live Demo

https://ayush-strx.github.io/signup-page/

## Tech Used

- HTML5
- CSS3
